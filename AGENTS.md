## GitHub safety circuit breaker — mandatory

Before any GitHub operation, follow `SandeepKumarHQ/Security-Guardrails/docs/policies/GITHUB-SAFETY-GUARDRAILS.md` and the organization public `.github/AGENTS.md`. GitHub is for source collaboration and short **human-approved repository CI**, never an agent, research crawler, model inference, media rendering, scheduler, backup, persistent service or general compute runtime; these belong on approved local/VPS infrastructure. Do NOT create or modify `.github/workflows/*` without explicit human permission and running the local `SandeepKumarHQ/Automation/scripts/check_github_actions_policy.py` preflight. Cron forbidden by default. CI limits: <=15-minute job, <=2 parallel, <=8 matrix, no retries, required concurrency, read-only permissions, <=3-day artifacts. GitHub restriction/abuse/flagging-related 403, any 429/secondary rate limit, repeated permission failure, or unexpected hidden repo → STOP **ALL GitHub writes and retries**, preserve exact response, never evade through alternate accounts/runners, and require owner approval before resuming. >3 repos or >20 GitHub writes needs scoped owner approval. Do not self-approve exceptions or enable commercial GitHub Pages production hosting by default.
