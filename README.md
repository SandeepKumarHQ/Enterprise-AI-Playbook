# Enterprise AI Playbook

Evidence-based reference knowledge for real AI integration in enterprise environments.

**Current status:** editorial and document contracts only, not a published collection of validated enterprise deployments.

## Scope
Architecture, FDE delivery, AI integration with existing enterprise systems, agent orchestration, security, identity and governance, evaluation and observability, change management, deployment economics, production reliability, operational rollout and incident handling.

## Knowledge-first publishing
`Knowledgebase canonical records → playbook outline → claim-by-claim kb_refs → technical/economic/security review → public approval → versioned guide → measured reader/engineering feedback → new Knowledgebase contribution`

Every factual guide references exact canonical KB IDs/versions and authoritative source links. Reusable implementation examples include test conditions and state whether synthetic or production-tested. Do not publish empty placeholders as completed guidance.

## Publication artifacts
- `guides/`: independently useful reviewed guides.
- `patterns/`: enterprise architecture and integration pattern pages.
- `templates/`: guide/architecture contracts and QA.
- `references/`: source/Knowledgebase IDs and reproduction notes.

Start from [GUIDE template](templates/GUIDE.md). Later derivative assets can go to LinkedIn, newsletter, website and slide decks without repeating underlying research.
